Expand description

Fault injection point for the parttest error-path tests (F0X-75).

fault_inject!(Step, v => injected, normal) evaluates injected (with the armed value bound to v) when a fault armed at FaultStep::Step fires, and normal otherwise. Without the parttest feature it expands to normal alone, so neither the fault state nor the injected branch exists in the build. fault_inject!(Step @ key, v => injected, normal) does the same at a step that names what it works on (the target VMSA’s GPA for the retire steps), so a fault armed for one target leaves the others alone. fault_inject!(if cond => injected, normal) is the same switch on a condition over parttest-only state.
