SNP_GUEST_REQUEST command to request a key derived by the PSP.

The key is derived from a chip-unique root (VCEK or VMRK) mixed with the VMPL and whichever guest fields the request selects, so a different measurement, policy or TCB yields a different key. Layouts match struct snp_derived_key_req / snp_derived_key_resp in Linux include/uapi/linux/sev-guest.h and the SEV-SNP firmware ABI.
