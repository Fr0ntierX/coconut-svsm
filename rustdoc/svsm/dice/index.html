DICE layer 0 for the CMVM monitor (F0X-80).

The monitor’s Compound Device Identifier comes from a VMPL0 key the PSP derives from the VCEK, mixed with this guest’s launch measurement, guest policy and reported TCB. The same SVSM image, launched with the same policy on the same chip at the same TCB, gets the same CDI; any of those changing gives a different one. The VMRK is not used: it changes on every launch.

The alias key is derived from the CDI the same way cmvm-dice derives it in uPolaris, and bound into a VMPL0 attestation report as REPORT_DATA = SHA-512(REPORT_DATA_TAG || SEC1 point). That report, signed by the VCEK, is the hardware root endorsement: it says this measurement holds this alias key.

The CDI and the alias private key never leave VMPL0.
